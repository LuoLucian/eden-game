# 🌿 伊甸园团建游戏 — 完整部署教程

> 适合零基础小白，按步骤操作即可！

## 🎮 游戏规则说明

### 基础规则
- 每位玩家初始 **10,000 积分**
- 每轮在 **60 秒**内必须用 **2,000 积分**投票
- 未投票者直接扣 2,000 积分

### 三种苹果
| 苹果 | 阵营 |
|------|------|
| 🍎 金苹果 | 金银阵营 |
| 🥈 银苹果 | 金银阵营 |
| 🍒 红苹果 | 红色阵营 |

### 胜负判定（少数派获胜）

| 情况 | 结果 |
|------|------|
| 金银票数合计 < 红苹果 | 金银 +1000，红苹果 -2000 |
| 红苹果 < 金银合计 | 红苹果 +1000，金银 -2000 |
| 金银 = 红苹果（平局） | 全部 -2000 |
| 没人投红，金 < 银 | 金苹果 +1000，银苹果 -2000 |
| 没人投红，银 < 金 | 银苹果 +1000，金苹果 -2000 |
| 没人投红，金 = 银 | 全部 -2000 |
| **全员投红苹果** | 🎉 **全体胜利！** |

## 📦 第一步：安装 Node.js

1. 打开浏览器，访问 **https://nodejs.org/zh-cn/**
2. 点击 **"LTS（长期支持版）"** 下载按钮
3. 双击下载好的安装包，一路点 **"下一步"** 安装
4. 安装完成后，打开 **命令提示符**（Win+R，输入 cmd，回车）
5. 输入 `node --version`，看到版本号（如 v20.x.x）表示安装成功

---

## 🚀 第二步：启动游戏

### 方法一：双击启动（推荐）

1. 找到项目文件夹 `eden-game`
2. 双击 **`启动游戏.bat`** 文件
3. 第一次运行会自动安装依赖（约1-2分钟，需要网络）
4. 看到类似下面的内容说明成功：

```
🌿 ========== 伊甸园游戏服务器已启动 ==========
📺 大屏展示端: http://192.168.x.x:3000/display/
🎮 后台控制端: http://192.168.x.x:3000/admin/
📱 玩家扫码端: http://192.168.x.x:3000/player/
=============================================
```

### 方法二：命令行启动

```bash
# 进入项目目录
cd C:\Users\DELL\WorkBuddy\Claw\eden-game

# 安装依赖（只需第一次）
npm install

# 启动服务器
```

## 🌐 第三步：连接各端设备

### ⚠️ 重要：所有设备必须连接同一个 WiFi！

启动后，命令行窗口会显示你的局域网地址（类似 `192.168.x.x`），记下这个地址。

#### 📺 大屏端（投影仪）
- 在连接投影仪/大屏的电脑上，打开浏览器
- 输入地址：`http://192.168.x.x:3000/display/`
- 按 **F11** 进入全屏模式
- 会显示二维码和游戏实时画面

#### 🎮 后台控制端（主持人电脑）
- 在主持人电脑浏览器中打开：`http://192.168.x.x:3000/admin/`
- 可以控制游戏开始、下一轮、强制结束等

#### 📱 玩家端（手机）
- 玩家用手机**扫描大屏上的二维码**，或手动输入：`http://192.168.x.x:3000/player/`
- 输入昵称即可加入

## 🎯 第四步：游戏流程

```
主持人操作                    大屏/玩家端反应
─────────────────────────────────────────────
1. 分享玩家端链接/二维码      玩家扫码输入昵称加入
2. 等待玩家都加入后            大屏显示玩家人数
3. 点击"开始游戏"              所有手机进入投票界面
                               倒计时60秒开始
4. 等待或点击"强制结束本轮"   显示本轮结果和积分变动
5. 点击"下一轮"               重新开始投票
6. 重复步骤3-5，轮数自定
7. 点击"结束游戏"             展示最终排行榜
```

## ❓ 常见问题

### Q：玩家扫码后打不开网页？
A：确认手机和电脑**连接同一个 WiFi**，检查命令行中的IP地址是否正确。

### Q：启动后找不到IP地址？
A：打开命令提示符，输入 `ipconfig`，找到"无线局域网适配器"下的"IPv4 地址"。

### Q：安装依赖时报错？
A：可能是网络问题，尝试切换到其他网络，或使用手机热点。

### Q：玩家刷新页面 / 锁屏后数据会丢吗？
A：不会。手机端会保存服务端签发的身份令牌（token），刷新或锁屏后自动凭 token 回到原记录，不会产生重复玩家，也不会串到别人身上。

### Q：多少人可以同时玩？
A：局域网条件下支持 10-100 人，超过 100 人可能需要更好的网络设备。

### Q：能在互联网上使用吗（不在同一WiFi）？
A：需要额外配置，如使用 ngrok 等内网穿透工具，或部署到云服务器。

## 🔧 自定义配置

如需修改游戏参数，打开 `server/index.js`，找到以下几行：

```javascript
const INITIAL_SCORE = 10000;  // 初始积分
const VOTE_COST = 2000;       // 每轮投票费
const WIN_REWARD = 1000;      // 胜利奖励
const LOSE_PENALTY = 2000;    // 失败惩罚
const ROUND_TIME = 60;        // 每轮时间（秒）
```

修改数字后保存，重新启动服务器即可生效。
